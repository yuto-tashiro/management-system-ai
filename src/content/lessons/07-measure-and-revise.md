## 問い

あなたのサービスで、顧客にとって「良くなった」とは、何がどう変わることでしょうか。それを、どこまで言えて、どこからは言えないでしょうか。

## 考え方

### ヘルスケアのサービスは「複雑介入」

運動プログラム、職場での健康支援、コンディショニング、介護予防――ヘルスケアのサービスの多くは、たくさんの要素が、人・組織・環境という文脈の中で作用して効果を生みます。医学研究ではこれを複雑介入と呼び、MRC／NIHRのフレームワークが、開発・実現可能性・評価・実装の各段階で、文脈・プログラム理論・不確実性・利害関係者を考慮しながら介入を磨き続ける方法を示しています。

この考え方は、事業としてのサービスを体系化するときにもそのまま使えます。

### まず、ロジックモデルを1枚描く

| 段階 | 例 |
| --- | --- |
| 投入資源 | 専門職2名×月8時間、評価ツール、現場責任者の協力 |
| 活動 | 初回評価、職場での短時間の運動、月1回の振り返り |
| 直接の成果 | 参加者数、実施回数、実施率 |
| 短期の成果 | 本人が感じる体の負担、運動習慣 |
| 中期の成果 | 体調を理由にした早退・欠勤の変化（部署単位） |
| 最終的な変化 | 長く安心して働き続けられる職場 |

描いてみると、「どこを測れば、何が言えるのか」が見えてきます。

### RE-AIMで、いま測れるものを2〜3個選ぶ

効果（Effectiveness）だけを測ろうとすると、小さな会社ではほとんどの場合、比較群も十分な人数もそろいません。RE-AIMの5軸から、**いま現実に測れるもの**を選びます。

- **Reach（到達）**：対象者のうち、参加した人の割合と特徴
- **Effectiveness（効果）**：成果の変化（比較がない場合は「変化が観察された」まで）
- **Adoption（採用）**：導入した部署・施設の数と特徴
- **Implementation（実施）**：計画どおり実施できた割合、変更した点
- **Maintenance（維持）**：数か月後も続いているか

### 負担・有害事象・文脈も記録する

成果だけでなく、参加者や現場の負担、痛みの訴えなどの有害事象、繁忙期や人間関係などの文脈を記録します。量的なデータは規模で勝る組織にかないませんが、**利用者がどんな言葉で困りごとを表現したか、導入担当と現場の評価がどう違ったか**といった文脈データは、現場に入っている人にしか取れない資産です。

本人の主観（一人称）、関わる人が感じ取ったもの（二人称）、測定（三人称）の三つがずれているときこそ、重要なことが起きています。

### 言えることと、言えないこと

| 観察 | 言えること | 言えないこと |
| --- | --- | --- |
| 前後比較で数値が改善 | 変化が観察された | 改善がプログラムによるもの（比較群がない） |
| スコアが高い人ほど調子がよい | 人と人の違いに関連がある | 同じ人のスコアを上げれば調子がよくなる |
| 参加者の満足度が高い | 参加者は満足している | 参加しなかった人にも同じ価値がある |

この表を報告書に入れるだけで、法人の担当者からの信頼は変わります。

### 改訂までやって、一巡

記録を要約して保管するだけでは、サービスは良くなりません。**観察 → 仮説 → サービス改訂 → 次の検証**の4段で、何を変えるか、誰が反映するか、どう確かめるかまで決めて、初めて一案件の経験がサービスの提供能力になります。変えないと判断した場合も、理由と再検討の条件を残せば有効な記録です。

## 判断に使う問い

- 顧客にとっての「改善」を、対象・指標・時間幅で書けるか。
- 測る指標は、いま現実に測れるものか。
- 負担と有害事象を記録する仕組みはあるか。
- 報告書に「言えないこと」を書いたか。

## 実践課題

1. [サービス理論図（ロジックモデル）](/worksheets/logic-model/)を描き、RE-AIMから指標を2〜3個選ぶ。
2. 直近の案件から重要な観察を1つ選び、[サービス改訂カード](/worksheets/revision-card/)を書く。
3. 次の案件では、[契約前に合意する事項](/worksheets/pre-contract/)で「どの指標を、いつ、どの形式で取るか」を決めてから始める。

## ヘルスケア領域での注意

- 個人の健康データを集める場合は、同意・匿名化・保管方法を先に決める。研究として発表する可能性があるなら、倫理審査の要否を事前に確認する。
- 個人間の違いと、同じ人の中での変化を混同しない。相関を因果として語らない。
- 有害事象が起きたときの連絡先と対応手順を、実施前に決めておく。
