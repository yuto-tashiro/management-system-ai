## 問い

同じ経験を何度も積めるのは、**どんな顧客の、どんな場面**でしょうか。

## 考え方

### 絞り込みは「機会を捨てること」ではない

身体は誰にでもあるので、極端に言えば全人類が顧客候補です。それがセラピストやトレーナーの強みでもあり、弱みでもあります。少人数の会社で対象を絞らないと、提供方法も、発信も、蓄積されるデータも、すべてが散らばります。

小さい会社にとって絞り込みとは、**同じ経験を何度も積める場所を選ぶこと**です。

### 4つの条件で書く

| 条件 | 例 |
| --- | --- |
| 領域 | ヘルスケア・ウェルビーイング（職域の健康） |
| 相手の事業段階 | 製品はあるが、売れ続ける事業にはなっていない |
| 規模・単位 | 会社ではなく、事業を動かす3〜10名のチーム |
| 最終顧客 | 法人・施設（toB） |

4条件が決まると、問い合わせが来たときに「これは自社の対象か」をその場で判断でき、対象外であれば紹介先を示せます。

### 購買に関わる人ごとに価値を翻訳する

法人の購買には、複数の人が関わります。それぞれの関心に合わせて、身体の知見を**相手の言葉**に翻訳します。

| 身体の言葉 | 企業の言葉 |
| --- | --- |
| 身体的な不調 | 欠勤、プレゼンティーイズム、離職 |
| 認知機能 | 労働安全、ヒューマンエラー、生産性 |
| 睡眠・疲労 | シフト設計、人材定着、事故リスク |
| 介護予防 | 事業継続、地域課題、保険財政 |

### 今動く理由（Trigger）と、思い出される場面（CEP）

課題があることと、今動くことは別です。資金調達、新製品の発表、実証の終了、補助金の採択、責任者の交代など、**今対話する理由**になる出来事を観察します。

また、シャープらの研究は、ブランドの成長には多くの顧客に「思い出される」ことが重要だと示しています。あなたのサービスが思い出されるべき場面（カテゴリー・エントリー・ポイント）を、顧客の言葉で書き出しておきます。例：「実証が終わったのに、本導入が決まらない」と感じたとき。

### 対象外の条件と、反証条件

ICPと同じくらい大事なのが、**対象外の条件**（Negative ICP）です。例：安価な作業外注が目的、社内に責任者がいない、根拠を飾りとしてしか使わない。

そして、この顧客像が間違っていると分かるサイン（反証条件）も書いておきます。例：同条件の3社に提案して、どこも次の打ち合わせに進まない。

### 初期の熱心な顧客と、主流の顧客は違う

初期に買ってくれた熱心な顧客の声だけで判断すると、まだ知らない多数の顧客を見落とします（ムーア『キャズム』）。初期顧客の条件のうち、何が本質で、何が偶然だったかを分けて考えます。

## 判断に使う問い

- 4条件で、問い合わせの可否をその場で判断できるか。
- 利用者・導入担当・決裁者それぞれに、何を価値として伝えるか書けるか。
- 対象外の相談を、誰に紹介できるか。
- この顧客像を「間違いだった」と判断する条件を決めたか。

## 実践課題

1. [顧客と利用場面シート](/worksheets/icp/)を記入する。
2. ポジションの一文を書く：「私たちは、［誰］が抱える［課題］に対して、［固有の知識・経験］を用い、［望ましい変化］を実現する会社である。」
3. 一文を信頼できる3人に見せ、反応を記録する。

## ヘルスケア領域での注意

- 企業の言葉に翻訳するとき、従業員個人を選別・評価する用途に使われないよう、利用目的を合意する。
- 「生産性が上がる」などの表現は、根拠の範囲を超えて断定しない。言えるのは何が観察されたかまで。
