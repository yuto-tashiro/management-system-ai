## 資金繰りは、実験を続けるための体力

ビジョンや探索が大切だとしても、現金がなくなれば会社は活動を続けられません。新規事業やプロダクト開発は、売上が立つまで時間がかかります。マイクロ法人の財務は、節税のためだけではなく、**学習と実験を続ける時間を確保するため**にあります。

毎月、次の5つを把握しておきます。

1. 毎月の固定費はいくらか
2. 売上が減っても、何か月耐えられるか
3. 既存事業から探索へ、いくら投資できるか
4. 回収までに、どのくらい時間がかかるか
5. 撤退の基準は何か

### 固定費を小さく保つ

0→1でよくあるつまずきは、初期費用をかけた設備・店舗・システムが固定費になり、試行回数が減ることです。最初は手作業で提供する、既存の場所を借りる、協力者と組む――固定費を小さく保つほど、許容損失の範囲で試せる回数が増えます。

### 補助金・共同研究は「時間を買う手段」

補助金や共同研究は、事業化に必要な時間を買う手段であって、それ自体がゴールではありません。採択が目的化すると、採択後に売上へつながらない計画になりがちです。申請の段階で、「採択後12か月で何を検証し、何を売上につなげるか」を書けているかを確認します。公募要領は回次ごとに変わるため、必ず当該回次の原文で確認します。

## 契約と知財

### 契約前に決めること

| 項目 | 確認すること |
| --- | --- |
| 範囲・期間・成果物・終了条件 | 何をどこまでやるか、何をもって終わりとするか |
| 対価と支払い条件 | 金額、支払時期、追加作業の扱い |
| データの所有と利用範囲 | 誰が持ち、誰が何に使えるか。匿名化・集計化の方法 |
| 成果物・知財の帰属 | 報告書・方法論・コードは誰のものか |
| 事例としての公開 | 公開してよい範囲と、同意の取り方 |
| 秘密保持 | 何が秘密情報か、期間、例外 |
| 責任の範囲 | 損害が生じた場合の責任の上限 |

[契約前に合意する事項](/worksheets/pre-contract/)のワークシートを使うと、抜け漏れを減らせます。

### 共同開発の知財は、成果が出る前に決める

複数社が関わるプロジェクトでは、どの成果がどの会社の資産になるか、誰が特許を出願するか、知財に関わらない組織はどこかを、開発が本格化する前に整理します。成果が出てから話し合うと、関係が壊れます。出る前に決めておけば、全員が安心して協力できます。

### 名義と表記

法人の分析・報告資料の名義を統一しておくと、資産として蓄積しやすく、承継や売却の際にも整理しやすくなります。契約も、可能な限り経営者個人ではなく法人名義にします。

## 保険・安全・個人情報

確認しておきたい主な論点です。

- **賠償責任保険**：運動指導・施術・研修など、身体に関わるサービスでの事故に備える。パートナーの加入状況も確認する
- **安全・事故時の対応**：中止の判断基準、受診勧奨の基準、連絡先、記録の方法を事前に決める
- **個人情報**：健康に関する情報は要配慮個人情報にあたることが多い。取得・利用・第三者提供・安全管理の方法を決め、医療・介護分野のガイダンスを確認する
- **情報セキュリティ**：端末・クラウド・AIツールのアクセス権限、退任・離脱時のアカウント停止

## 働き方と体制

- **パートナーとの関係**：業務委託として組む場合、指揮命令の仕方によっては雇用と見なされることがある。責任と成果で依頼する設計は、この点でも理にかなっている
- **資格と業務範囲**：資格が必要な行為を誰が担うか。資格の名称の使い方
- **経営者の不在**：自分が1か月休んだら何が止まるか。止まるものを一つずつ減らす

## 承継と出口

事業が経営者個人に依存したままだと、承継も売却もできません。継続・承継・売却・合併・休眠のどれを選んでも困らないよう、事業資産と契約を年に一度整理します。会社売却・バイアウトの実務や、既存事業を買って伸ばす道を早めに知っておくと、選択肢を冷静に比べられます。→ [講座12](/lessons/12-intangible-assets/)

## 相談先の目安

| 論点 | 主な相談先 |
| --- | --- |
| 税務・会計・決算 | 税理士 |
| 契約・知財・紛争 | 弁護士、弁理士（特許・商標） |
| 労務・社会保険 | 社会保険労務士 |
| 登記・定款 | 司法書士 |
| 補助金・公的支援 | 公的な支援機関（よろず支援拠点、商工会議所など）、各制度の窓口 |
| 個人情報 | 個人情報保護委員会の相談窓口 |
