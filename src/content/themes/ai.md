## AIは小ささの意味を変える

少人数の会社では、一人が営業・企画・制作・経理・研究・顧客対応を兼ねます。AIは、人を増やさなければできなかった仕事の一部を支援し、固定費を大きくせずに調査・制作・分析・開発・運営の幅を広げてくれます。

ただし、AIを導入すれば自動的に強い会社になるわけではありません。**何を人間が担い、何をAIに任せ、何を会社の能力として残すのか**。この設計がAI時代の経営です。

## 8つのループすべてに横串で入る

| ループ | AIの使いどころ |
| --- | --- |
| SEARCH | 社会理解と情報整理の高速化。現場の観察を渡して構造化させる |
| POSITION | 自社資源と競合の比較。案件リストから「伸びる構造」の仮説を出させる |
| EXPERIMENT | 試作品をつくるコストの低下 |
| SERVE | 価値のない摩擦（転記・整形・議事録）の削減 |
| LEARN | 暗黙知の言語化と組織知化 |
| TRUST | 発信・編集・多言語化の増幅 |
| SYSTEMIZE | 専門知のプロダクト化 |
| RENEW | 仮説検証と事業更新の高速化 |

## 「使う」から「仕込む」へ

多くのAI活用は「そのつど質問する」段階で止まっています。毎回ゼロから説明し、毎回違う答えが返ってくる――これはチームというより、優秀だが記憶のない外注先です。次の3つを用意すると、出力の質が変わります。

1. **会社の前提**：誰に何を提供しているか、大事にしている原則、使ってはいけない表現、名義・表記のルール
2. **手順（スキル）**：繰り返す業務を、他者が実行できる粒度で書いたもの
3. **判断材料**：ケース記録、原則集、テンプレート、うまくいかなかった事例

重要なのは、これらをつくる作業そのものが、会社の形式知化になっていることです。**AI向けに手順を書くことは、結果として人間に渡せる形式知をつくること**でもあります。マニュアルは面倒で誰も読まないかもしれませんが、「AIに正しく仕事をさせるために書く」という動機があると書けます。そして書いた瞬間に、それは組織の資産になります。

## 業務を4つに分ける

| 分類 | 内容 | 例 |
| --- | --- | --- |
| 人間が行う | 専門判断、重要な対話、最終意思決定、断定の強さの調整 | 初回面談、報告会での質疑、限界の記述 |
| AIが支援する | 調査、下書き、比較、分析、編集、反証出し | 公募要領の要件整理、構成案、統計処理の補助 |
| 自動化する | 定型連絡、転記、集計、リマインド | 議事録の整形、進捗共有 |
| やめる | 目的がなく価値を生まない業務 | 読まれない中間報告、過剰な体裁調整 |

AIを入れると「何でも効率化しよう」と考えがちですが、価値の低い仕事を効率よく続けるより、**まずやめる**ほうがよい場合もあります。四半期に一度、「やめる」欄を意識的に埋めてください。

## 人間に残す5つの役割

1. **顧客理解**：言葉になっていない不安、関係性、背景を理解する
2. **専門判断**：不確実な状況で、知識と経験を統合して判断する
3. **意味づけ**：データや出来事が、自社のビジョンにとって何を意味するか考える
4. **関係構築**：顧客、仲間、協力者との信頼をつくる
5. **責任**：最終的な意思決定と、その結果を引き受ける

身体を通じた関わりの中で育つこれらの能力は、現場に立ち続けている専門職が日々訓練しているものでもあります。

## 共通の作業フロー

どの業務でも、次の5工程で進めます。AIが担うのは②③の一部で、①④⑤は人間が起点です。

1. **前提を渡す**：会社の前提・顧客情報・制約・禁止事項
2. **素材をつくる**：調査・下書き・分析・図表
3. **反証を出す**：この結論が間違っているとしたらなぜか
4. **検収する**：事実・数値・出典・断定の強さ
5. **資産化する**：手順・判断基準・データを会社へ残す

### 反証を必ず挟む

AIは同意してくれやすいため、意識的に反論を求めないと、思い込みを補強するだけの道具になります。成果物を出す前に、次の問いを一度通してください。

- この結論が間違っているとしたら、どんな理由が考えられるか
- 反対の立場の専門家なら、どこを突くか
- この数値・根拠のうち、出典が確認できていないものはどれか

## 情報の線引き

患者情報、顧客企業の機密、個人情報を扱う場合は、利用するAIの規約、契約、保存範囲、匿名化、アクセス権限を確認します。

| 区分 | 例 | 扱い |
| --- | --- | --- |
| 入力してよい | 公開情報、公募要領、自社の作成物、匿名化済みデータ、構造だけにした案件情報 | 通常利用 |
| 条件付き | クライアント提供資料、未公開の事業計画 | 契約・規約を確認のうえ利用し、範囲を記録に残す |
| 入力しない | 氏名を含む個人データ、匿名化の対応表、他社の機密を含む資料、同意範囲外の研究データ | いかなるツールにも入力しない |

この線引きを整備しておくと、企業クライアントに「うちはこういう運用をしています」と説明でき、それ自体が信頼になります。WHOも、健康領域のAIについて、人間の自律性、安全性、透明性、説明責任、公平性、持続可能性を原則として示しています。

## 発信でAIを使うとき

| AIに任せてよい | 人間がやる |
| --- | --- |
| 構成案、見出し、表現の調整、要約、翻訳、図解、誤字チェック、過去の文章との整合性確認 | 一次体験の記述、判断の根拠、断定の強さの調整、誰かを傷つけないかの確認、公開するかどうかの決定 |

AIの文章は、しばしば言い切りすぎます。専門職として言えることと言えないことの線は、資格と倫理を持つ人間にしか引けません。自分が経験していないことを経験したように書かない、都合の良いデータだけを使わない、AIの一般論を自分独自の方法論のように見せない――短期的に目立っても、長期的な信頼資本を損ないます。

## 効率化の成果は、値引きではなく資産化に
