## なぜ固有の論点が必要か

一般の経営書や起業の方法論は、ヘルスケア・ウェルビーイング領域でもそのまま役に立ちます。ただし、この領域では次の点でつまずきやすくなります。

1. **根拠**：「効果がある」と言いたくなるが、言える範囲は限られている
2. **規制**：医療機器、広告表示、医療広告、個人情報に関する法令がある
3. **使う人と払う人のずれ**：利用者と支払者が違うことが多い
4. **データと同意**：健康に関する情報は、取扱いに特に配慮が必要

> 「効果がある」と言えることより、**「どこまで言えて、どこからは言えないか」**を示せることが、専門職の事業の信頼になる。

## フェーズ別の論点

| 論点 | 0→1 | 1→10 | 10→100 |
| --- | --- | --- | --- |
| 使う人と払う人 | 利用者・家族・施設・企業・自治体・保険者のうち、誰が払うかを最初に確認する | 決裁者ごとの価値（欠勤、安全、離職、保険財政など）に翻訳する | 支払い構造そのものを変える提案（制度・保険者連携）を検討する |
| エビデンス | 既存研究で言えることを整理し、言い過ぎない | ロジックモデルとRE-AIMで、現場で検証できる指標を設計する | 共同研究・学会発表・指針への接続で、分野の参照点になる |
| 表現と規制 | 医療機器への該当性、景品表示法、健康増進法の誇大表示を確認する | 広告・LP・営業資料の表現ルールを文書にする | 認定制度や基準づくりに関わり、業界の信頼を底上げする |
| データと同意 | 要配慮個人情報の扱い、同意の範囲を決めてから取得する | 匿名化・突合・保管の手順を標準化する | PHRや共同データ基盤への参加と、ガバナンスを設計する |
| 社会的価値 | 誰のどんな不条理を扱うかを明確にする | 量的指標に加え、本人の言葉・現場の文脈を記録する | 売上と並べて、地域・現場・パートナーに残った価値を報告する |

## 使う人と払う人

ヘルスケアでは、サービスを使う人とお金を払う人が違うことがよくあります。

- 高齢者が使い、自治体や家族が払う
- 従業員が使い、会社が払う
- 患者が使い、保険者が払う
- 選手が使い、チームやスポンサーが払う

払う人にとっての価値は、利用者にとっての価値と同じとは限りません。法人向けには、身体の知見を相手の言葉に翻訳します。

| 身体の言葉 | 企業・組織の言葉 |
| --- | --- |
| 身体的な不調 | 欠勤・プレゼンティーイズム・離職 |
| 認知機能 | 労働安全・ヒューマンエラー・生産性 |
| 睡眠・疲労 | シフト設計・人材定着・事故リスク |
| 介護予防 | 事業継続・地域課題・保険財政 |

## 根拠の扱い方

### 根拠には種類がある

このサイトでは、すべての主張に[根拠ラベル](/about/#evidence)をつけています。公的指針、研究知見、実務書の枠組み、HILUCOの実務仮説、HILUCOの検証済み手順。あなたの営業資料や発信でも、根拠の種類を区別して示すことを勧めます。

### 健康に関する主張の書き方

- 対象者・条件・成果指標・時間幅を明示する
- 研究で観察された関連を、あなたのサービスの因果効果として語らない
- 個人間の違い（人と人の差）と、同じ人の中での変化を混同しない
- 比較群のない前後比較からは「変化が観察された」までしか言えない
- 治療効果や疾病の予防効果を断定しない

### 段階に応じた根拠の水準

英国NICEのデジタルヘルス評価基準（ESF）は、技術の機能とリスクに応じて求める根拠の水準を変えています。日本では、AMEDが医学会と連携して予防・健康づくりの指針を整備しており、経済産業省もエビデンスが不十分なまま販売されるヘルスケアサービスの問題を整理しています。自社サービスに関係する指針があるか、まず確認します。

## 表現と規制

ここでは主な論点だけを挙げます。実際の判断は、最新の法令・ガイドラインを確認し、必要に応じて専門家に相談してください。

| 論点 | 確認すること |
| --- | --- |
| 医療機器への該当性（薬機法） | 疾病の診断・治療・予防を目的とする機器やプログラムは、医療機器に該当しうる。アプリやツールは、使用目的と機能の表現で該当性が変わる |
| 誇大な表示（景品表示法・健康増進法） | 実際より著しく優良と示す表示や、健康の保持増進の効果について事実に反する・誤認させる表示をしない |
| 医療広告（医療法） | 医療機関の広告にはガイドラインがあり、ウェブサイトも対象。医療機関と組む・発信を支援する場合は公開直前に最新版を確認する |
| 資格と業務範囲 | 医療資格が必要な行為と、そうでない行為（運動指導・健康支援など）の線引き。資格の名称の使い方 |

## データと同意

健康に関する情報（病歴、健康診断の結果、診療情報など）は、個人情報保護法上の**要配慮個人情報**にあたることが多く、取得には原則として本人の同意が必要です。医療・介護分野には個人情報保護委員会と厚生労働省のガイダンスがあり、改正が続いているため最新版を確認します。

案件の契約前に、次の3つを決めます。

1. **同意の範囲**：個人データは同意書、施設単位のデータは経営者・管理者との協議。AIによる解析を含むなら、そのことを明記できているか
2. **匿名化の手順**：いつ・誰が・どう置き換えるか。元データと対応表の保管場所を分ける
3. **入力してよい情報の線引き**：どの種類の情報を、どのツールに入れないか

詳しくは[AIに入力してよい情報の線引き](/worksheets/ai-rules/)と[契約前に合意する事項](/worksheets/pre-contract/)を使ってください。

## このサイト自身の編集基準

- 健康に関する主張は、対象者・条件・成果指標・時間幅を明示し、根拠の範囲を超える一般化や治療効果の断定をしない。
- 健康データ・顧客情報を、学習フォームやワークシートで集めない（ワークシートの入力は、あなたのブラウザにだけ保存されます）。
- AIの出力は草案・探索・反証の補助に限り、健康情報・専門判断・断定表現・最終責任は担当者が確認する。
- 読了数やアクセス数を、健康成果・事業成果の証拠として扱わない。
